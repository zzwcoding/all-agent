## 做了什么

1. **归一化实现（AC1）**：`tools/l5_score.py` `aggregate_question()` 改归一化计算——
   **归一分（normalized）= Σ(维中位×weight) / Σweight**（0–5 量纲），归零问（disqualifier
   触发或维度 0 分）按 0 计；**原始加和（rawTotal）= Σ(维中位×weight)** 仅作报告追溯列。
   门槛回到 design §4.2 原语义：**单问归一 ≥3 且归一分集中位 ≥4.0 且无 0 分问**——权重集
   今后调整不再连动门槛（P2-A 的根因消除）。`evaluate()` 条件键随语义改名：
   `perQuestionTotal`→`perQuestionNormalized`、`noDisqualifier`→`noZeroScore`（zeroed 清单
   带 zero_reasons）；`render_md()` 逐问双列「归一分: X ｜ 原始加和: Y」，条件行/结论全用
   归一分；`render_json()` questions[] 增 `normalized`/`rawTotal`/`zeroed`/`zero_reasons`
   字段。报告数字显示统一 `_fmt()`（round 2 位，4.333…→4.33）。
2. **维度 0 分归零语义（票面新裁决）**：「任一维度 0 分=该问归一 0 分」实现为**按中位口径**

## 取舍

- **「维度 0 分」取中位口径**：票面「任一维度 0 分=该问归一 0 分」未写明按采样还是按中位
  ——取**维中位 0 才归零**：聚合进总分的是中位，归零判据与被聚合量同源；单采样 0 分是
  离群，交给中位机制吸收（与 §4.3 同哲学）。单测双向钉死（中位 0 归零/单采样 0 不归零），
  specs 注意事项 2 写明口径，若 Owner 要按采样口径改走票一行翻转。
- **归零问 rawTotal 记 0 而非记实际加和**：与旧版 disqualifier「按 0 分计」一致、与「该问
  0 分」裁决字面一致；可追溯性不损失——逐维中位表仍在，实际加和可复算，归零缘由由
  zero_reasons 显式承载。
- **反注入句加到出厂集 3 份样例 rubric（超出票面字面的 12 份）**：specs rubric 格式说明
  已把「scoring_prompt 末句必含反注入声明」写成格式要求，3 份样例是格式样板与 spec 互为
  镜像——不补则样板自己失格；样例在 Touches 清单（fixtures/l5-scoring/）内。一致性
  disqualifier 未加样例（票面只裁 12 份真集，样例 disqualifiers 是 mock 内容非格式承诺）。
- **断言真源指针迁移**：specs/l5_score.md 与 assertions.json 描述的 AC 真源由 tickets/42
  改指 tickets/49（协议第 8 条：出厂断言以票面 AC 表为正）——票 49 AC 表覆盖归一化全量
  验收面，42 表保留为一期基线注记。
- **out/green.* 重 gen 留在工作树不 commit**：rubric 反注入句改变输入指纹（fde8ef84…→
  新值），AC4c 探针 rmtree 重 gen 字节确定；随本票全部改动留树，由主窗口按协议第 ⑩ 条
  复跑四闸后一并入账（交接包「不 commit」）。

## 坑

- **加和量纲 mock 的失真是静默的**：lowmedian 旧样本在归一后不是「变松/变紧」而是
  **变道**——②单点红变①②双红（Q1 0.6/Q2 1.0 连带踩①），lowtotal 则因 acc=0 新触维度
  归零（①③双红）。只跑断言看「仍 exit 1」会误判语义未失真——必须逐问实算归一分并核对
  「只踩哪条条件」。教训：门槛语义一变，正负样本的**条件覆盖面**要重新对表，不是只看
  退出码。
- **子串兼容的断言是侥幸不是绿**：AC4b 的 `全集中位 3` 恰好匹配 `全集中位 3.0`，退出码与
  outputContains 双绿——但「3」的语义已从加和变归一。本次把描述按新实算改写、AC4a/AC3c
  显式演进，不把兼容当正确；演进处全部入本篇对照表。
- **改参照答案/rubric 前先查联动面**（lessons/49 坑节同款反向）：本次改 12 份 rubric 前
  核过三面——锚例引参照原文零改动（只动 scoring_prompt 末尾与 disqualifiers 尾行）、
  CORE-01–15 机判断言不读 rubric、check_citations 不读 rubric，故 CIT×6 与 core 断言零
  连带；out/green.* 指纹漂移是唯一联动，重 gen 清偿。
- **两问形态下条件①单点红不可达**：归一量纲上单问上限 5.0，两问集 [x<3, 4.0] 的中位必
  <4.0——单测 test_exit_1_low_total 在归一后必然①②连红（旧加和量纲 [0,12] 中位 6 能
  ①-only），注释如实写明并指认 ①-only 形态由出厂集 AC4a 三问 mock 钉死；单测层不硬凑。
