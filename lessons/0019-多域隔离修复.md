# lessons/0019 · 多域隔离修复（票 76）

## 做了什么
schema_check L2 悬空引用判定集按 manifest 域值分桶（defs_by_domain）+ 一致性对四桶按域分桶逐域闭合——跨域借 ID 与跨域绑定不再静默也不拉红他域。

## 坑
1. 第十轮 T4 用不存在的 ID 验证跨域隔离属假阴性——真实验证需用真实存在的他域 ID 注入；
2. phase13 报告初稿把第十二轮的战果（擦图 P1、幻觉率 1.8-2.2%）误写进第十一轮括注——两轮审查内容交叉污染，Owner 审阅时差点误判；
3. 票号撞号（原 72 与第十轮撞号改号 74）——多会话并行施工时票号分配需跨会话协调。

## 取舍
- 域分桶 vs 全局并集：分桶后每域独立判定，跨域借 ID 照红——这是「域间隔离」的正确语义（各域独立自治，跨域引用需显式提案）。
