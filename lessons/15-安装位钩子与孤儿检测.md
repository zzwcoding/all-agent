## 取舍

1. **注册表收敛规则 = 现清单 ∪ {登记过、正本已删、安装位仍存的退役候选}，而不是"无脑写现清单"**：若 sync 无脑重写为现清单，"删正本→顺手 sync"会把孤儿洗出注册表，此后 --check 永远不再报——孤儿检测就被最日常的操作击穿。收敛规则下除名只有两条路：`--prune --yes` 删净残留（显式退役），或安装位目录自然消失（自然退役）。sync 检出退役候选时 stderr 提示 prune 处置，rc 仍 0（sync 本职完成了，退役是另一个显式动作）。代价：注册表不完全等于"当前清单"，语义记在模块 docstring 与本条。
2. **孤儿判定严格三要素，注册表是唯一凭据**：安装位里 29 个非本仓 skill（archify/sdd-flow 等）无登记，--check 不报、--prune 不删（专测 test_other_peoples_skills_never_orphans 钉死）；反向也钉了"没登记过的残留不判孤儿"（三要素缺一不可）。注册表是 sync 维护的本仓管理面清单，不是安装位全量清单。
3. **注册表写在所有拷贝之后 + 临时文件 os.replace + 内容不变不重写**：半途失败（mock 拷贝中途抛 OSError 实测）注册表一字不动、无 .tmp 残骸；字节级幂等让"连跑 sync"对注册表零扰动。OSError 统一捕获为 rc2 并明示"未落任何新状态"——比裸 traceback 可测、可控。
4. **钩子极简、无短路缓存**（主窗口防踩坑 4 照办）：git status 判断+上次通过缓存的方案会引入状态与不确定性；每次提交全量 `--check`（4 skill 十几个文件，毫秒级）确定且足够。钩子也不塞四闸（ci.sh 已管）。对未配 hooksPath 的其他 clone：脚本只是躺在 tools/hooks/ 的普通文件，git 不调用即零副作用，无需自检。
5. **--prune 默认 dry-run、--yes 才删、不接 skill 名**：破坏性操作加确认闸（与仓内"删除需理由"文化一致）；孤儿按注册表全量认定、不做选择式删除——孤儿数量天然少（个位数），简单确定性优先。
6. **symlink 闸范围=两侧×（现清单∪在册名）**：比"只查本次所选"宽，宁可全拒也不放软链进删除/拷贝路径；不做递归解析（票面裁决）。prune 真删前对每个目标防御性再查一次 islink。
7. **HookGate 走 tempfile 里真 git**：红线只禁"真实 git config/真实 ~/.agents"，临时仓内 `git config core.hooksPath tools/hooks` 是 tempfile 作用域的仓内局部配置，不越界；拷贝**本仓真实钩子脚本**进临时仓测试，测的是真产物而非测试替身。git 缺失时 skipTest 兜底。

## 坑

- **macOS `/var`→`/private/var` resolve 老坑换个马甲再踩**：JSON 报告里孤儿路径是 resolve 后的 `/private/var/...`，测试期望值必须同样 `.resolve()`；更阴的是人读输出用 `assertIn(str(self.dst/"alpha"), out)` 因子串包含（`/private[/var/...]`）侥幸变绿——精确相等断言才暴露。凡路径进断言，要么都 resolve，要么别用子串。
- **退役候选提示写 stderr、测试断言在 stdout**：`run_main` 分捕两流，断言错位直接 fail。警示性信息走 stderr 是对的，测试跟流走。
- **`hooks/*` 不加进布局表 tools patterns，钩子脚本自己先红归档闸**：`*.py` 匹配不上 `hooks/pre-commit`（fnmatch `*` 跨 `/` 但后缀不合）。新增目录收编文件时先跑归档闸，别等 CI。
- **tempfile 真 git 测试的三件套**：仓内局部 `user.email`/`user.name`（否则 commit 死在身份缺失）、`init -q`（压默认分支提示）、基线提交本身就会过一遍钩子（顺带成为 AC2 的前置验证）。
