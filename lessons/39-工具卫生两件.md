## 取舍

- **缺键闸挂 `_validate_references` 而非捕获装配段 KeyError**：L0 裁决语义是「捕获后走结构化配置错误」，观测行为等价（exit 2+同报文+零输出）；挂校验段让拒绝发生在任何装配之前，与该函数既有「指空即拒」同址同风格，也天然覆盖 skill 侧 M7-in-slice 路径。
- **skill 侧负变体不立出厂集**：出厂集断言面=票面 AC 表（AC1 只给 app-pack-gen 负变体）；skill 侧同款修复以单测钉死（合成域剃行→exit 2），不为它扩 fixtures/skill-pack-gen 副本——出厂集纪律「断言面必须对得上 AC 声明面」。
- **纪律句蒸馏而非搬移全文**：裁决钉的是 `(编号,名称,一句话)` 三元组形态；全文搬移则常量不是「一句话」、且静态长文里的实现细节（--impact、全等→字段⊆候选词分层序）属运行时细则，真源在 retrieval-waterfall.md——发布物静态卡留一句话纪律+真源指针（ROUTING_NOTE）即够。
- **编号沿用 ①②③④ 不改「一级…四级」**：core 实现的瀑布级称谓是一级…四级（waterfall_level 字段），发布物表现形态是 ①…④；常量注释里写明一一对应（①↔一级·显式锚定 等），渲染面与既有断言（① 显式锚定/④ 可拒答）零扰动。
- **常量形状测试放 test_skill_pack_gen 不放 test_semantic_service_core**：后者不在票面 Touches 清单（初稿曾加、自查边界时撤回并收敛到前者）——常量消费/同步面在 skill_pack_gen，其自身契约（四步/编号/非空）随 import 同一性断言一并钉住，不为此破 Touches 边界。

## 坑

- **「不产残包」的断言形态**：ConfigError 路径天然不落盘（build_package 在任何 write 之前），但断言要真闸得住回归——单测与出厂探针都传 `--out` 进临时目录再验目录为空/不存在，不靠「应该不会写」的推理。
- **test argv 传 Path 踩 argparse**：`--out` 值传 `Path` 对象在 argparse 3.14 直接 `TypeError: 'PosixPath' object is not subscriptable`——run_main 的 argv 一律 str()，与被测面无关的环境坑，留痕防复发。
- **既有断言钉面先行核对省了一次断言翻新**：防踩坑 #3 担心的「断言钉了旧静态文案」实测不存在（出厂集只钉节头、单测只钉步骤名与编号），常数化因此零断言改动——「断言随常数化演进」条款本票未触发，改文案前先 grep 断言面这两分钟花得值。
