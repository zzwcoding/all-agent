## 坑

- **管道/重定向不是坏味道，坏在吞退出码**：`cmd | grep` 查内容、`cmd > log` 留输出都是正当用法——错在之后**把管道/重定向表达式当被测闸的退出码来源**或让红灯失去可见通路。判定式问句只有一句：这个复合命令的失败，还能不能让调用方看见非零？
- **`$?` 语义三连坑同根**：管道后 `$?`=末段命令的码（43/44/52/57 四次）、重定向不保护退出码但切断可见性（168640c）、`&&` 链在掩码后一路假绿（50da7f3 实证）——全部是「复合命令的退出码 ≠ 首段命令的退出码」一个根。跑闸就用最笨的形态：单命令、看退出码、要摘要再跑第二遍或 tee。
- **教训只写 commit message = 没写**：第三次教训在 commit message 里活了半年无人见（审查九原文「仓内零留痕」）——commit message 是给 git log 的，不是给 lessons/ 的；重复发病的教训必须进 lessons 并入协议，否则下次还是靠人记。
