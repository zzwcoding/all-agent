## What to build

## 设计裁决（L0 已定）

- **现状精确边界**（L0 /tmp 实验）：纯无 id 文件被空壳守卫接住；引用悬空被 dangling-ref 接住；唯一逃逸形态="无 id 元素混入合法元素且自身引用全部有效"。
- **修法**：模型文件主集合（aggregates/behaviors/rules/roles 等，按模型类型既有集合键）内的**每个字典都按元素枚举**——不再以"有 id 键"为枚举前提；无 id 元素由既有 requiredElementFields 机制自然报"缺必填字段 id"（id 本就在各模型必填集首位，无需新违规码）。空壳守卫语义收窄为"主集合键缺失或集合为空"（集合里有字典就不算空壳，逐元素报缺 id）。
- **嵌套结构不受影响**：attributes[]/refRules[] 等子结构字典不是元素，不进元素枚举（它们由 ref 扫描与字段检查覆盖）——实现时必须验证这条不误伤（valid-domain 的属性字典无 id 是合法的，全量绿灯是硬证明）。
- 无机读表变更 → 不进 CHANGELOG 版本；schema.md 违规码语义注记 + specs/schema_check.md 断言表补行。
