### 1.4 关键代码

#### R.java（统一返回格式）

```java
package com.his.report.common;

import lombok.Data;

@Data
public class R<T> {
    private int code;
    private String message;
    private T data;

    public static <T> R<T> ok(T data) {
        R<T> r = new R<>();
        r.code = 200;
        r.message = "success";
        r.data = data;
        return r;
    }

    public static <T> R<T> error(String msg) {
        R<T> r = new R<>();
        r.code = 500;
        r.message = msg;
        return r;
    }
}
```

#### CorsConfig.java

```java
package com.his.report.config;

import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
public class CorsConfig implements WebMvcConfigurer {
    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/**")
                .allowedOriginPatterns("*")
                .allowedMethods("*")
                .allowedHeaders("*");
    }
}
```

### 模块二：门诊运营分析

#### 3.4 科室接诊量排行

```
GET /api/v1/outpatient/dept-rank?startDate=2022-06-01&endDate=2022-06-10
```

**SQL**：
```sql
SELECT dept_name,
       SUM(total_visits) AS total_visits,
       SUM(refund_count) AS refund_count,
       ROUND(SUM(refund_count)*100.0/SUM(total_visits),2) AS refund_rate
FROM his_report_db.ads_dept_visit_rank
WHERE visit_day BETWEEN #{startDate} AND #{endDate}
GROUP BY dept_name
ORDER BY total_visits DESC;
```

**返回示例**：
```json
{
  "code": 200,
  "data": [
    {"deptName": "心血管内科", "totalVisits": 35, "refundCount": 3, "refundRate": 8.57},
    {"deptName": "神经内科", "totalVisits": 28, "refundCount": 1, "refundRate": 3.57}
  ]
}
```

#### 3.5 医生接诊量 TOP15

```
GET /api/v1/outpatient/doctor-rank?startDate=2022-06-01&endDate=2022-06-10
```

**SQL**：
```sql
SELECT doctor_name, dept_name, SUM(visit_count) AS visit_count
FROM his_report_db.ads_doctor_visit_rank
```

#### 3.6 就诊状态流转（漏斗图）

```
GET /api/v1/outpatient/status-flow
```

#### 3.8 支付方式收入占比

```
GET /api/v1/finance/payment-ratio?startDate=2022-06-01&endDate=2022-06-10
```

**SQL**：
```sql
SELECT regist_method,
       SUM(revenue) AS revenue,

FROM his_report_db.ads_revenue_payment

ORDER BY revenue DESC;
```

### 模块五：疾病诊断分析

#### 3.13 诊断疾病 TOP20

```
GET /api/v1/disease/diag-top20
```

> 需要关联 `his` 库的 `disease` 表取中文名

**SQL**：
```sql
SELECT d.disease_name,
       COUNT(mrd.disease_id) AS diag_cnt
FROM his.medical_record_disease mrd
JOIN his.disease d ON mrd.disease_id = d.id
GROUP BY d.disease_name
ORDER BY diag_cnt DESC
LIMIT 20;
```

---

#### 3.14 ICD-10 疾病章节分布

```
GET /api/v1/disease/icd-dist
```

**SQL**：
```sql
SELECT LEFT(d.diseaseICD, 1) AS icd_chapter,
       COUNT(*) AS cnt
FROM his.medical_record_disease mrd
JOIN his.disease d ON mrd.disease_id = d.id
WHERE d.diseaseICD IS NOT NULL AND d.diseaseICD != ''
GROUP BY LEFT(d.diseaseICD, 1)
ORDER BY cnt DESC;
```

#### 3.15 病历完整率

```
GET /api/v1/disease/record-complete
```

**SQL**：
```sql
SELECT
  COUNT(*) AS total,
  SUM(CASE WHEN readme IS NOT NULL AND readme != '' AND readme != '未填写' THEN 1 ELSE 0 END) AS has_readme,
  SUM(CASE WHEN present IS NOT NULL AND present != '' AND present != '未填写' THEN 1 ELSE 0 END) AS has_present,
  SUM(CASE WHEN history IS NOT NULL AND history != '' AND history != '未填写' THEN 1 ELSE 0 END) AS has_history,
  SUM(CASE WHEN allergy IS NOT NULL AND allergy != '' AND allergy != '未填写' THEN 1 ELSE 0 END) AS has_allergy,
  SUM(CASE WHEN physique IS NOT NULL AND physique != '' AND physique != '未填写' THEN 1 ELSE 0 END) AS has_physique
FROM his.medical_record
WHERE delmark = 1;
```

### 模块六：患者画像分析

#### 3.16 年龄-性别金字塔

```
GET /api/v1/patient/age-pyramid
```

**SQL**：
```sql
SELECT
  CASE
    WHEN age BETWEEN 0 AND 18 THEN '0-18岁'
    WHEN age BETWEEN 19 AND 35 THEN '19-35岁'
    WHEN age BETWEEN 36 AND 50 THEN '36-50岁'
    WHEN age BETWEEN 51 AND 65 THEN '51-65岁'
    ELSE '66岁以上'
  END AS age_group,
  gender,
  COUNT(*) AS cnt
FROM his.register
WHERE age IS NOT NULL
GROUP BY age_group, gender
ORDER BY age_group, gender;
```

#### 3.18 复诊率

```
GET /api/v1/patient/revisit-rate
```

**SQL**：
```sql
SELECT
  COUNT(DISTINCT case_number) AS total_patients,
  COUNT(*) AS total_visits,
  COUNT(*) - COUNT(DISTINCT case_number) AS revisit_visits,
  ROUND((COUNT(*) - COUNT(DISTINCT case_number))*100.0/COUNT(*), 2) AS revisit_rate
FROM his.register;
```

## 五、数据源配置说明

需要配置**双数据源**：

| 数据源 | 库名 | 用途 |
|--------|------|------|
| `hisReportDs`（主） | `his_report_db` | 11 个接口直接查 ADS 聚合表 |
| `hisDs`（副） | `his` | 7 个接口需要查源表做实时统计 |

在 IDEA 中使用 MyBatis-Plus 的多数据源插件 `dynamic-datasource-spring-boot-starter`，在 `pom.xml` 中加：

```xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>dynamic-datasource-spring-boot-starter</artifactId>
    <version>3.6.1</version>
</dependency>
```

然后 `application.yml` 改为：

```yaml
spring:
  datasource:
    dynamic:
      primary: his-report
      datasource:
        his-report:
          driver-class-name: com.mysql.cj.jdbc.Driver
          url: jdbc:mysql://192.168.100.200:3306/his_report_db?useSSL=false&serverTimezone=Asia/Shanghai
          username: root
          password: Root@123456
        his:
          driver-class-name: com.mysql.cj.jdbc.Driver
          url: jdbc:mysql://192.168.100.200:3306/his?useSSL=false&serverTimezone=Asia/Shanghai
          username: root
          password: Root@123456
```

在 Mapper 上用 `@DS("his")` 指定使用 `his` 数据源，不标注则默认用 `his-report`。
