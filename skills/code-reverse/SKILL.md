# code-reverse · 代码逆向（L1 工序，前端适配器）

把存量源码变成结构完备、能过语义闸的本体**草案**，外加一份**调用链素材**（代码符号→草案元素逐条映射+调用图），自下而上供业务 Owner 裁决。本 skill 机器通用：正文不含任何具体业务域知识，域素材只存在于出厂集与用户提供的输入里。

## 触发面 / 何时用

- 用户要「把这份源码/这个代码库逆向成本体草案与调用链素材」时使用。
- 不适用：从库表结构/DDL 逆向成本体（那是同族另一道前端适配工序的事）；从粗需求正向收敛（正向建模是另一道上游工序）；改已定稿本体（写入必经 MR，本 skill 只产草案不进仓）；运行期查询口径（那是运行时服务的事）。

## 输入输出契约

- reads：用户提供的源码文件或代码库（采信范围见 references/code-mapping-guide.md §1——类声明/字段/方法签名与方法体/常量定义与比较点/字面量集/真实调用点/import 与类型标注）；`ontology/schema/**`（schema 文档与两份机读表：模型注册表、依赖白名单）。
- writes：`ontology/<域>/**` 草案——域 manifest.json + 有证据的模型文件；`docs/code-reverse/<域>-调用链素材.md`——调用链素材（符号→元素逐条映射+源码 file:line 证据+调用链+疑点清单+明示不逆向清单，末节符号覆盖对照表）。只产草案，进仓走 MR。
- 依赖脚本：`tools/schema_check.py`（语义闸，修整步的判定器）。

## 工序（按序执行，每步产物落盘）

1. **输入清点与符号清单落盘**：通读源码，把公开符号（类/函数/常量约束/字面量集；字段与方法随类以点号登记）逐行列出并注 file:line 声明位——这是覆盖不变量的输入侧，清单与代码对不上，后面全部白做。
2. **结构抽取映射**：按 references/code-mapping-guide.md §2 总表逐条映射——类→聚合根候选、字段→属性、常量约束（常量定义+比较点两处直证）→规则候选、字面量集→字典候选；每条候选注源 `源码 file:line`，映射不出处即发明语义。
3. **调用图与调用链素材**：只从真实调用点提取调用链，逐跳注调用方/被调方 file:line；零调用点的孤儿方法登记疑点；调用链只作行为/调用素材，不产生对象间关联推断。
4. **三落点判定**：逐符号落三处之一——判据清晰可复述→草案元素候选；有代码片段无可复述业务语义（方法有状态改写但无触发主体/权限/时机）→挂起，manifest omittedModels 带理由豁免、不产空壳文件，符号进疑点清单；语言机制/非业务语义（构造器本体、形参变量）→明示不逆向清单（带理由）。**宁可挂起不可硬建**。
5. **生成草案+映射文件**：按 schema 公共字段与 ID 前缀约定落模型 YAML + manifest.json（profile 取注册表组合名，默认建议最小核心组合）；引用关系只从字段引用推导（构造器字段/类型标注），方向基数按证据直译并待 Owner 确认；草案头部固定声明「证据非权威，待 Owner 确认」；映射文件末节落符号覆盖对照表（逐符号→落点→元素/疑点编号→证据等级）。
6. **覆盖不变量自检**：符号清单 ×（对照表 + 草案 + 疑点/不逆向清单）双向核对，逐符号确认落点——任何一个符号三处皆无 = 漏覆盖，回步骤 4，不许带漏交付。出厂集探针是本步的机判参照实现。
7. **修整过语义闸 + 交 Owner 裁决**：跑 `python3 tools/schema_check.py <域目录>`，按报告逐条修复直到全过；交付时明示——草案与映射文件全部为证据面，对象划分/类型占位/关系/行为取舍均「待 Owner 确认」；Owner 裁决后按 MR 流程进仓。本 skill 不做 git 提交、不直改已定稿本体。

## 行为约定

- **草案头部固定声明「证据非权威，待 Owner 确认」**；交付物不得作为已定稿本体消费。
- **不发明源码里不存在的语义**：引用关系只从真实字段引用推导，调用链不产生关联；无可复述业务语义的方法不产行为元素（挂起）；值集不全的字面量集不建字典；无比较点的孤立常量只进疑点。
- **疑点不静默吞掉**：声明/写入分离、孤儿方法、唯一性无声明、类型未注解等可疑信号逐条登记（位置+特征+源码证据+待 Owner 问题）并回写草案对应对象描述——宁可多报不可漏报。
- **AI 只做格式转换与结构完备性**：业务语义（对象划分、口径、关系、行为取舍）必须人确认。
- 字典项/枚举项停用置 enabled: false 保留行，不删除；引用不得靠名称猜测。

## 出厂集（Seam）

`fixtures/code-reverse/`——合成迷你代码库两文件（中性域，类与字段/方法调用链/常量约束/字面量集四类素材齐）→ 断言草案过语义闸 + 符号覆盖探针正例 exit 0（AC1）、草案头部声明与 file:line 注源（AC2）、映射缺一个符号覆盖的负变体 exit 1（AC3）。改本 skill 工序描述前，先确认出厂集仍绿。
