# requirement-explorer · 需求探索（L1 工序，前端适配器）

把粗需求/粗 PRD 反问收敛成三节齐的**细稿**与结构完备、能过语义闸的本体**草案**，正向供业务 Owner 裁决。本 skill 机器通用：正文不含任何具体业务域知识，域素材只存在于出厂集与用户提供的输入里。

## 触发面 / 何时用

- 用户要「从粗需求/粗 PRD 反问收敛出细稿与本体草案」时使用。
- 不适用：从库表结构/DDL 逆向成本体（那是同族另一道前端适配工序的事）；改已定稿本体（写入必经 MR，本 skill 只产草案不进仓）；运行期查询口径（那是运行时服务的事）。

## 输入输出契约

- reads：用户提供的粗需求/粗 PRD 素材（采信范围见 references/questioning-guide.md §1——业务对象、属性、业务规则、角色称谓、流程描述，全部是文字面证据）；`ontology/schema/**`（schema 文档与两份机读表：模型注册表、依赖白名单）。
- writes：`docs/requirements/*.md` 细稿——三节缺一不可（收敛结论 / 开放问题清单 / 明示不建模清单，末节附关键词×三落点对照表）；`ontology/<域>/**` 草案——域 manifest.json + 有证据的模型文件。只产草案，进仓走 MR。
- 依赖脚本：`tools/schema_check.py`（语义闸，修整步的判定器）。

## 工序（按序执行，每步产物落盘）

1. **输入清点与关键词标记**：通读粗素材，识别实体与口径关键词（识别规则见 references/questioning-guide.md §2）；素材未标记的，本工序补标记并落关键词清单（逐行一词）——这是覆盖不变量的输入侧，清单与素材对不上，后面全部白做。
2. **三分类映射**：把素材内容按 references/req-to-onto-mapping.md §1 总表逐条映射——名词→对象/术语候选、动作→行为候选、约束→规则候选；每条候选记输入出处（可指认），映射不出处即发明语义。
3. **三落点判定**：逐关键词判定落点（判定树见 references/questioning-guide.md §3）——判据清晰可复述→落草案元素候选；含糊/缺判据/粒度未定→落开放问题清单；输入自述越界或判别边界缺失→落明示不建模清单（带理由）。**宁可多问不可硬建**。
4. **生成细稿+草案**：细稿三节（收敛结论/开放问题清单/明示不建模清单，每问固定三字段）+ 草案域目录（manifest.json + 有证据的模型文件；证据不足以支撑整模型的，profile 降组合并在 manifest omittedModels 逐个带理由豁免，不产空壳文件）。草案头部固定声明「AI 只做格式转换，业务必须人确认」。
5. **覆盖不变量自检**：关键词清单 ×（草案域文件 + 细稿两节）双向核对，逐词确认落点并在对照表登记——任何一个词三处皆无 = 未收敛，回步骤 3，不许带漏交付。出厂集探针是本步的机判参照实现。
6. **修整过语义闸**：跑 `python3 tools/schema_check.py <域目录>`，按报告逐条修复直到全过。本 skill 不做 git 提交、不直改已定稿本体。
7. **交 Owner 裁决**：交付时明示——细稿与草案全部为候选面，对象划分/口径/粒度/关系取舍均「待 Owner 确认」；开放问题清单是给 Owner 的提问清单，答完才谈定稿；Owner 裁决后按 MR 流程进仓。

## 行为约定

- **草案头部固定声明「AI 只做格式转换，业务必须人确认」**；交付物不得作为已定稿本体消费。
- **含糊表述不硬建模**：粗素材里的模糊时限、模糊归属、模糊粒度，一律进开放问题清单（三字段齐），不许直接翻译成属性/规则/结构——「未覆盖必须变成问题」，漏覆盖 = 本工序不合格。
- **问题三字段缺一不可**：问题 / 为什么问 / 影响哪个候选元素。字段齐是机判口径；问得好不好是人审面，机判不背书问题质量。
- **不发明素材里没有的业务语义**：零关系证据零关联；动作只有短语没有触发/前置/状态变更语义的，行为候选挂起不产文件；判别边界未给的概念（近义词、另一套事）进明示不建模清单。
- 细稿三节缺一不可；明示不建模必须带理由，理由指向输入原文。
- 字段值集不完整不建枚举；术语只收口径可复述的词，含糊词不进术语表。

## 出厂集（Seam）

`fixtures/requirement-explorer/`——固定粗 PRD 片段（中性域，【】标记关键词，含故意含糊表述）→ 细稿三节齐 + 草案过语义闸（AC1）、覆盖不变量探针正例 exit 0 / 漏覆盖负变体 exit 1（AC2）。改本 skill 工序描述前，先确认出厂集仍绿。
