# 检索瀑布判定细则（semantic-service · 域无关）

SKILL.md 定义四级瀑布与顺序；本文是每级的判定细则与边界。全文域无关：域知识只在本体仓，本文只定义「怎么查、怎么裁、何时停」。

## 0. 总则

- 顺序固定：显式锚定 → ID/名称解析 → 闭包装配 → 可拒答。逐级降级，不跳级、不回退重试猜测。
- 每级出口只有两种：命中的元素 ID 集，或「未命中」结论（进下一级/拒答）。禁止输出无 ID 的中间结论。
- 检索面裁剪在先：任何候选 ID 先过 §5 阵营检查，面外即走拒答分支（references/refusal-guide.md R1），不进入装配。

## 1. 一级 · 显式锚定

- 触发：问题文本带 @元素ID 记法（如 @AGG-XXX-001）。锚定即用户自报 ID，跳过名称猜测。
- 动作：`tools/graph_index.py <本体目录> --query <ID>` 确认存在；存在 → 直达装配（§3）；不存在 → 明确回「锚定 ID 未找到」，不猜近似拼写，降二级解析或四级拒答。
- 锚定 ID 先过检索面检查（§5）：面外元素同样拒答（如界面/屏幕类前缀），只说明阵营归属，不展开。

## 2. 二级 · ID/名称解析

- 无 @ID 时，从问题抽概念候选词（对象名/指标名/行为名/别名）。
- 候选 ID 的产生：通读候选域模型文件的 id/name/alias 字段人工对齐——图索引的 `--query` 是存在性确认器，不是搜索引擎；不引入登记面之外的检索脚本。
- 逐候选 `--query` 确认；全部未命中 → 结论「仓内没有该概念」进四级。**不猜**：不做模糊匹配、不凭名称相似度造 ID、不把「名字像」当「就是」。
- 命中多个（多义）：列候选各带 ID 与一句话区分，请用户锚定；不擅自合并、不挑一个代答。

## 3. 三级 · 闭包装配

- 命中节点后装配子图上下文，两个方向：
  - 正向 `--closure N`：它引用了谁（字典/关联/下游行为）。N 从 1 起，证据不足再加深，最多 3；
  - 反向 `--impact`：谁引用了它（行为 ownerEntity、流程、查询出口）——「对象有哪些行为」类问题靠反向收集。
- 装配产物 = 回答的证据集：只引用装配集内的 ID，集合外的关联不臆测。
- 口径类问题（指标含义/统计口径）必须装配**口径四件套**：承载字段（对象+属性）、校验规则、执行行为、查询出口；缺哪件就明说哪件缺（转四级缺件说明）。
- 非口径类（问对象/问行为）装配到能回答该问题的最小闭包即可，不为装配而装配。

## 4. 四级 · 可拒答

- 两类拒答分流（话术见 references/refusal-guide.md）：
  - R1 检索面外：ID 可解析但 camp 裁剪不过 → 说明阵营归属与拒答理由，不返回任何元素细节；
  - R2 仓内没有：解析穷尽未命中 → 拒答 + 缺件分层说明 + 近邻指路（真实存在、带 ID、标「非所问」）。
- 锚定失败/解析失败的话术并入 R2（references/refusal-guide.md R3）。
- 写意图不属拒答但同样止步：一律回「走提案流程」（references/refusal-guide.md R4），本服务不产文件、不改仓。

## 5. 检索面划界操作法（camp 裁剪）

- 机读依据：`ontology/schema/model-registry.json`（模型 → camp）+ `ontology/schema/model-deps.json`（ID 前缀 → 模型）。判定链：元素 ID 前缀 → 模型 → camp。
- 检索面 = **camp=business-core**；camp=build-contract（界面/屏幕类）一律面外。
- **划界只看 camp，不看 consumers**：consumers 只有 build 但 camp=business-core 的模型（如流程类）仍在检索面内；camp=build-contract 的模型即便声明了 consumers 也不进面。两表冲突时以注册表 camp 为准并按提案流程上报。
- **图索引没有阵营概念**：`tools/graph_index.py` 全量建图（含 build-contract 模型的节点与边）。阵营裁剪是本 skill 的工序职责——凡引用注册表判为面外的元素细节都是事故，先裁后答。

## 6. 判定速查

| 情形 | 判定 | 动作 |
|---|---|---|
| 问题带 @ID，ID 存在且在面内 | 一级命中 | 直达 §3 装配 |
| 问题带 @ID，ID 面外（camp=build-contract） | R1 | 拒答 + 阵营说明 + 指路 |
| 问题带 @ID，ID 不存在 | 锚定失败 | 不猜；降二级或 R2 |
| 无 @ID，名称命中唯一 | 二级命中 | §3 装配 |
| 无 @ID，名称多义 | 二级命中（多义） | 列候选带 ID 请用户锚定 |
| 无 @ID，名称穷尽未命中 | R2 | 拒答 + 缺什么 + 近邻指路 |
| 用户要改口径/补概念/修模型 | 写意图 | 回「走提案流程」 |
