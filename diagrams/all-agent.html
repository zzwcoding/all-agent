这张图是什么：All-agent 大总架构全景——编译器架构：左端 N 个前端适配器（多输入）→ 本体仓居中（唯一真源 IR）→ 右端 M 个后端生成器（多输出），下方运行时服务面供智慧大脑只读消费；外圈三个循环（业务语义/建造/元循环）让系统自迭代。正文对照 docs/prd.md。另两张图：sdd-flow2 内部解剖（sdd-flow2.html）、skill 层组织（skill-structure.html）。
怎么读：蓝框=普通节点；红框 🛡️=防护闸；实线=主流程（草案/构建/读取/消费），虚线=反馈回路/治理回路；暗灰虚线框=外部既有（Harness 用现成的 Kimi Code）。铁律：前端禁直连后端——一切经本体仓。

AGT智慧大脑：问答/问数/问智 → 统筹指挥本体运行期消费方POOL
POOL提案池：监督/自检/交互三源信号归一一次反馈=一处根因=一个 MRMRG
MRG人工审批 MR语义变更必须人拍板CORE
BE1–5应用包/Skill/MCP/分析报告/变更影响分析一份本体多处消费企业系统/平台
SDF2sdd-flow2：建造与改造全部件本体管不了的工程层由它接管FE/BE/GATE/SVC
META元循环：跨层探针+出厂集回归+信号路由表大架构自身的体检与进化SDF2 / CORE / MRG
BASEHarness 底座：长任务/上下文/调度不重造轮子，用现成 Kimi Code全体 skill
