这张图是什么：左半是单个 skill 的解剖（物理形态：薄壳→规约→出厂集，渐进披露发生在每个 skill 内部）；右半是 skill 群的逻辑包含层级（L0 编排 → L1 工序 → L2 共享规约 → L3 脚本 → L4 数据）。核心结论：skill 物理平铺、无目录嵌套，"大模块套小模块"是逻辑关系——靠卡上显式依赖行表达。正文对照 docs/design-sdd-flow2.md §1–2。
怎么读：蓝框=普通节点；红框 🛡️=防护闸；实线=组成/编排调用（需显式声明），虚线=只读引用；暗灰虚线框=外部依赖（不在本体系治理范围）；嵌套子图=物理组成（目录内），并列子图=逻辑分层。
