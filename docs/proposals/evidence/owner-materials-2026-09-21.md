## PROP-011 井号归一表全集【Owner 已确认 2026-09-21】

**旧写法形态变体**（以规范形 N-02 为例）：
- V1 去连字符：`N02`、`N2`
- V2 乱连字符：`N-2`、`N_2`
- V3 零宽/空白污染：`N 02`、`N-02 `（尾随空格）、全角连字符 `N－02`
- V4 大小写混写：`n-02`、`n02`

**规范化算法**（伪代码，幂等）：
```
normalize(wellId):
  s = wellId.trim().upper().replace('－','-').replace('_','-')
  s = s.removeAll(' ')                       # 去内部空格
  m = match(s, '^([A-Z]+)\\-?(\\d{1,3})$')   # 字母前缀 + 可选连字符 + 1~3 位数字
  if not m: return { ok:false, raw:wellId }  # 进问题单，不猜测
  return { ok:true, canonical: m.1 + '-' + pad(m.2, 2, '0') }   # 数字左补零至 2 位
```
规则要点：前缀保留原字母（本域仅 N，算法不限定以便未来扩 P/A 等）；数字右两位左补零；
匹配失败**不猜测归一**，落问题单闭环（与补录超窗同通道）。

## PROP-025 机采系统能效三级公式【Owner 已确认 2026-09-21】

- **系统级**：η_sys = Σ(各井有效功率) / Σ(各井输入功率) × 100%
- **单元级**（单井/机采单元）：η_unit = P_eff / P_in × 100%，其中 P_eff = Δp × Q（有效功率，kW），P_in = 实测输入电功率（kW）
- **设备级**：η_dev = 设备输出功率 / 设备输入功率 × 100%（按设备逐台：电机/皮带/泵 分段计算后连乘校核）

单位声明：**load = 载荷，单位 kN；current = 电流，单位 A**。载荷与冲程数据用于计算光杆功率（设备级输入），电流用于电机输入功率核算，均不直接进 η_unit 分子。

自检：三级均为"有效功率/输入功率×100%"同构，单位声明与 8 源表中 equip_status 可采集字段（载荷/电流）对应，不引入新源表。

## PROP-018 递减增油基线拟合参数【Owner 已确认 2026-09-21】

- **基期窗口**：措施前 **6 个月**日产油序列（缺失日按 R-16 插补精神取邻值，不补零）。
- **拟合方法**：指数递减 q(t) = q₀·(1−dₐ)^t，q₀=基期最后 7 日均值；**dₐ 按基期首月 vs 末月产量比反解**：dₐ = 1 − (q_末月均 / q_首月均)^(1/5)。
- **取值范围约束**：dₐ 落在 [0, 0.05] 采信；< 0 取 0（无递减）；> 0.05 视为基期受干扰（措施前已在递减异常），转人工复核，不自动拟合。
- 增油 = 见效期逐日实测产油 − 逐日 q(t)，逐日为负计 0。

自检：基期 6 个月 + 见效期 90 日（PROP-024）在 120 口井日产数据时间跨度内可算；dₐ 上限 0.05 与渤海常规油田月递减量级相符（拟定经验值，待 Owner 认可）。

## PROP-029 有效产量开井日历折算支公式【Owner 已确认 2026-09-21】

**完整算式**：
```
有效产量(开井日历折算支) = Σ_i ( oilOutput_i × openDays_i / 24 )
```
- i 遍历当期在产采油井；oilOutput_i 为该井当期折算日产量（t/d）；openDays_i 为当期**开井小时数**（非整数小时按 0.5 h 粒度记录）。
- 使用场景：当期存在非全月生产井（新投产/措施停工/检修）时，**开井日历支与剔检支并列计算、双口径披露**——剔检支（从分子剔除检修井全月产量）用于与历史可比，开井日历支（按实际开井小时折算）用于平台当月真实贡献口径；两支差异 > 3% 时在口径页并列展示并注明差异来源。

自检：与"跨月检修按日历天数劈分"既有口径并列不冲突（劈分管检修归属，本支管开井折算）；24 为小时/日折算系数，量纲自洽。
