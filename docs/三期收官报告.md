## 5. 三期方法论收获（按分量排序）

1. **"带红入仓"事故→第⑩条**（本期的制度性收获）：收官追加文件未复跑四闸导致红灯入仓（8a4a632）——应急清偿后固化为协议第⑩条"最终树四闸"，并在票 48/49 收官中实战执行。事故变制度的完整链路又一例。
2. **运行时子 agent 注入**：评分器不内嵌模型调用、只消费评分结果 JSON——"AI 判"层接入"纯 Python 零依赖"仓的通用形态；独立子 agent 零上下文天然解决评者≠答者。
3. **哈希锚定自动失效**：人审结论锚定被审版本 sha256，再生即失效回落待人审——与 --check 同哲学（逐字节判"版本作不作数"），单人仓人审闸的低摩擦承载形态。
4. **新闸首跑抓真缺陷即价值自证**：L3 首跑抓 2 处存量缺陷、L5 首跑抓 Q8 矛盾——闸上线第一个动作就还债，是"闸写对了"的最强证据。（勘误 2026-09-20 票 54：「2 处存量缺陷」同 §3 注——实为同一缺陷两参数，措辞勘误。）
5. **量纲归一化教训**：L5 门槛先在加权分上漂移，Owner 裁决归一回 0–5 原语义+反向回归钉死——指标改造必须带"旧语义反向回归"，防静默改口径。
6. **设计案两拍制**：复杂机制先出设计案过目（B 线批次三）再拆施工票（C 线）——裁决记录落设计案文末（§9/§8），ADR 只落正式裁决项，文档层级不混。
