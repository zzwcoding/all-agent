## 5. 学到哪（一期方法论收获，按分量排序）

1. **出厂集先行（红→绿）是被验证最狠的纪律**：四个 skill 票全用「先写固定输入+断言→实跑全红→手工产出参照产物→转绿」，参照产物天然成为 skill 工序的标准样本与回归锚；改任何 skill 前先看出厂集是否还绿，从未失效。
2. **闸要有机读真源，人读文档只是目录页**：AC4/AC5 的判定真源在 model-deps.json、AC6/AC7 在 model-registry.json（lockedFields）、归档在 repo-layout.json+archive-registry.json——两份机读表一致性由闸互查。文档会说谎（或过时），机读表+闸不会。
3. **「前缀即类型标签」一个约定撑起三个消费方**：ID 前缀→模型→camp/consumers，profile 裁剪、检索面划界、影响分析方向全靠它；省掉了整套类型标注机制。
4. **保守建模的价值在走查日兑现**：db-reverse 零外键→零引用的草案，逼得工序②的每一条引用都必须回 R5·§5 找业务依据——「不发明」最终变成了「可追溯」。
5. **域无关纪律是 skill 可复用的前提**：四张卡正文 grep 域词为零，渤海域知识只活在 fixtures/ 与 ontology/；本期四个 skill 换域即用。
6. **图索引无阵营概念是特性**：全量建图+消费方裁剪（semantic-service 先裁后答），让同一个图同时服务运行时与治理面，代价是消费方必须自律（Q5 的走查缺口即此纪律的实测）。
7. **机械面+人工面的双层表述是诚实完备的唯一方式**：字典 code 不进图、表达式字段依赖不进图、物质平衡联动不可达——报告/答案把这些如实划出，比假完备可信。
