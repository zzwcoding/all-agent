# ADR 0002 · 外部审查窗替代票级 code-review

状态: 已采纳
日期: 2026-09-19
结论: 票级 code-review 由独立外部审查窗替代，裁决成立且为常设。替代不是取消审查，而是把审查从"票内即时一道工序"改为"批级独立深审 + L0 复跑复核 + 报告落盘 docs/reviews/ + 整改票闭环"。
底图: docs/reviews/（四轮审查报告为证：phase1 票 03–09 / phase2-batch1 票 10–12 / phase2 票 13–19 / phase3 票 20–24 + sdd-flow2 符合性审计）
遗留: 无（阶段 7 定期体检制度化与豁免清单复核属 sdd-flow2 审计另条漂移，不入本裁决范围）。

## 背景

sdd-flow2 阶段 5（实现）要求每票过一道 code-review。本仓实际执行中，票级即时 review 一直由外部审查窗替代：每批收官后由独立只读审查窗做多路深审（按票/按面分路，审查窗自行实跑 CI 与工具取证），L0 对关键论断在本仓复现复核（复跑），报告落盘 `docs/reviews/`（不以对话转述存活），发现项经拆票进入整改票闭环（票 20、票 25/26 即前三/四轮审查的整改票）。sdd-flow2 符合性审计（phase3 报告）指出该替代"质量更高但属未经 ADR 裁决的方法论改动"——本 ADR 补裁决入账。

## 裁决

替代成立且为常设：本仓一切票的验收审查走外部审查窗模式，不设票级 code-review 工序。执行细则见 AGENTS.md 续跑协议第 7 条（审查报告必落盘 `docs/reviews/`，整改票引用审查结论须引落盘路径）。

## 权衡

- 得：审查窗上下文独立（不带施工窗的自我确认偏差）；多路并行深审覆盖面更大（票面 × 横切面对账 × 方法论符合性）；成本更低（不为每票单开审查会话）；审查窗自行实跑 CI 与工具，论断可复现、可复核。
- 失：票级即时性弱化——问题发现从"票内即时"后移到"批级收官时点"，同类坏味道可能在批内多票间复制。补偿：批级审查一次覆盖整批 + 整改票闭环收偿；同款失败模式连续出现（如锚点静默失配两次）直接触发协议流程补丁（续跑协议第 6 条）。

## 生效范围与推翻条件

- 生效范围：本仓全部开发票（一期、二期及以后各批）的验收审查环节；sdd-flow2 方法论本体（~/.agents/skills/sdd-flow2）不受影响。
- 推翻条件：审查窗失灵（报告关键论断被 L0 复核证伪）或漏检 P1 级问题连续两轮，则重议本裁决——考虑恢复票级 review 或增设批内中间审查点。
